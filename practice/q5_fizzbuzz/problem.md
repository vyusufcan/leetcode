# Q5 - FizzBuzz

Write a function that takes a number n and prints numbers from 1 to n with these rules:

- If the number is divisible by 3, print "Fizz"
- If the number is divisible by 5, print "Buzz"
- If divisible by both 3 and 5, print "FizzBuzz"
- Otherwise, print the number itself

## Examples

```
Input: 15
Output:
1
2
Fizz
4
Buzz
Fizz
7
8
Fizz
Buzz
11
Fizz
13
14
FizzBuzz
```
