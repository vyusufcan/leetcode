# Q10 - Word Frequency Count

Write a function that takes a string and returns a dictionary mapping each
word to how many times it appears.

Assume words are separated by spaces, and comparison should be
case-insensitive (`"The"` and `"the"` count as the same word).

## Examples

```
Input:  "the cat sat on the mat the cat ran"
Output: {"the": 3, "cat": 2, "sat": 1, "on": 1, "mat": 1, "ran": 1}

Input:  "Hello hello world"
Output: {"hello": 2, "world": 1}
```

## Expected output
Return a dictionary — don't use `print` inside the function.
