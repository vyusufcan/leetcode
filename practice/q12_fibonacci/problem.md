# Q12 - Fibonacci Sequence (Recursion)

Write a function that returns the nth Fibonacci number. Solve it using
recursion (the function should call itself).

Reminder: fib(0) = 0, fib(1) = 1, and every number after that is the sum
of the two before it.

## Examples

```
Input:  n = 0
Output: 0

Input:  n = 1
Output: 1

Input:  n = 6
Output: 8
```

## Expected output

Return the nth Fibonacci number — don't use `print` inside the function.
