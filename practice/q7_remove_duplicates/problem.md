# Q7 - Remove Duplicates

Write a function that takes a list and returns a new list with duplicates removed.
Preserve the original order.

## Examples

```
Input:  [1, 2, 2, 3, 4, 4, 5]
Output: [1, 2, 3, 4, 5]

Input:  [5, 5, 5, 5]
Output: [5]

Input:  [1, 2, 3]
Output: [1, 2, 3]
```

## Expected output
Return the new list.
