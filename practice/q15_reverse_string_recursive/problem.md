# Q15 - String Reversal (Recursion)

Write a function that returns a string reversed. Solve it using recursion
(no loops) — the function should call itself.

Note: this is different from Q1 (Reverse a String), which didn't require
recursion. Here the point is to practice breaking the string into a first
character + the rest, then combining them recursively.

## Examples

```
Input:  ""
Output: ""

Input:  "a"
Output: "a"

Input:  "hello"
Output: "olleh"
```

## Expected output

Return the reversed string — don't use `print` inside the function.
