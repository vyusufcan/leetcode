# Q13 - Factorial (Recursion)

Write a function that returns `n!` (n factorial). Solve it using recursion
(the function should call itself).

Reminder: `0! = 1`, and for `n > 0`, `n! = n * (n-1)!`.

## Examples

```
Input:  n = 0
Output: 1

Input:  n = 1
Output: 1

Input:  n = 5
Output: 120
```

## Expected output

Return the factorial of `n` — don't use `print` inside the function.
