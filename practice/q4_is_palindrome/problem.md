# Q4 - Is Palindrome

Write a function that takes a string and returns True if it is a palindrome, False otherwise.

A palindrome reads the same forwards and backwards.

Do NOT use slicing ([::-1]) to solve it.

## Examples

```
Input:  "racecar"
Output: True

Input:  "hello"
Output: False

Input:  "madam"
Output: True

Input:  "abc"
Output: False
```
