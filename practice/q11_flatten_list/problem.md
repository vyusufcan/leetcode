# Q11 - Flatten a Nested List

Write a function that takes a nested list (a list that may contain other
lists, to any depth) and returns a single flat list containing all the
values in order.

## Examples

```
Input:  [1, [2, 3], [4, [5, 6]], 7]
Output: [1, 2, 3, 4, 5, 6, 7]

Input:  [[1, 2], [3, [4, [5]]]]
Output: [1, 2, 3, 4, 5]

Input:  [1, 2, 3]
Output: [1, 2, 3]
```

## Expected output
Return a flat list — don't use `print` inside the function.
