# Q9 - Is Prime

Write a function that takes a positive integer and returns `True` if it's a
prime number, `False` otherwise.

A prime number is a number greater than 1 that has no divisors other than
1 and itself.

## Examples

```
Input:  7
Output: True

Input:  8
Output: False   (divisible by 2 and 4)

Input:  1
Output: False   (1 is not prime by definition)

Input:  2
Output: True    (smallest prime)
```

## Expected output
Return `True` or `False` — don't use `print` inside the function.
