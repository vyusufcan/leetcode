# Q14 - Sum of a List (Recursion)

Write a function that returns the sum of all numbers in a list. Solve it
using recursion (no loops) — the function should call itself.

## Examples

```
Input:  []
Output: 0

Input:  [5]
Output: 5

Input:  [1, 2, 3, 4]
Output: 10
```

## Expected output

Return the sum — don't use `print` inside the function.
